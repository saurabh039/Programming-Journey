# 🚀 Programming Journey – Interview Cheat Sheet

> **Purpose**
>
> This cheat sheet is a curated revision guide containing only the most valuable programs from the Programming Journey repository.
>
> Every program included here introduces at least one of the following:
>
> - A new programming concept
> - A reusable problem-solving pattern
> - An algorithmic optimization
> - An interview-relevant implementation
> - An advanced language or system-level feature
>
> It is designed for quick revision before coding assessments, technical interviews, and placement preparation.

---

# 🎯 Selection Criteria

A program is included only if it satisfies one or more of the following:

- 🟢 Introduces a fundamental programming concept
- 💡 Demonstrates a reusable programming pattern
- ⚡ Provides an optimized implementation
- 🟡 Represents a frequently asked interview problem
- 🔴 Covers an advanced programming concept

Programs that only repeat previously learned logic are intentionally omitted.
